My FIDO MDS Explorer

Explore FIDO Metadata Service authenticator records, AAGUIDs, certification status and capabilities in a searchable visual catalog.

The FIDO Metadata Service (MDS) publishes structured information about authenticator models. It includes identifiers such as AAGUIDs, authenticator capabilities, and metadata status information. That data is useful, but a long list of records or raw JSON is not always the easiest way to explore it.

My FIDO MDS Explorer presents the catalog as a visual, searchable application. Browse authenticators by vendor or product, search identifiers, and inspect individual metadata records without starting from a table.

Explore FIDO metadata

⛶ Full page

The explorer includes metadata from different manufacturers, including HID Crescendo products. Its purpose is to make the underlying FIDO records easier to navigate, not to replace certification evidence or deployment testing.

Data freshness: The explorer uses a bundled FIDO MDS snapshot, refreshed monthly through site releases. It does not fetch or verify live metadata in the browser. Consult the FIDO Alliance Metadata Service for authoritative information and current status.

The application is an independent project and is not an official FIDO Alliance service.
