Registration and authentication
Registration calls navigator.credentials.create(); authentication calls navigator.credentials.get(). Run a test to see the exact operation and options.

   
API call · illustrative
await navigator.credentials.create({ publicKey: options });

   
What to look for
  • Challenge: random data that binds the response to the current request.
  • RP ID and origin: credentials are scoped to the relying party.
  • Authenticator selection: browser hints and policy are not physical device detection.

Hardware troubleshooting
  • USB-C: connect a FIDO2 authenticator and complete the browser prompt.
  • NFC: hold a FIDO-enabled card near the phone when prompted, if supported by the platform.
  • Smart cards: PKI/PIV alone is not a FIDO2/WebAuthn authenticator.
  • NotAllowedError can mean cancellation, timeout or other conditions; it does not prove hardware absence.
