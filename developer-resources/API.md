# JSON Inspector API

`EdwardcherJSONInspector.open(data, title)` opens a read-only modal. `data` must be JSON-serializable; `title` is an optional string (default: JSON Inspector). The method returns no value. Load the classic script after the document body exists and keep its CSS beside it. Each call snapshots data using JSON serialization. Cyclic values, BigInt and undefined root values are unsupported; functions and undefined object properties are omitted by JSON serialization. Use plain JSON values. No editing, storage or transmission of inspected data. Clipboard access depends on browser permissions and secure context. Test large payloads and browser compatibility locally. Escape closes the modal; j/k moves, h/l collapses/expands, Enter toggles, / searches, n/N moves between matches, g/G jumps. Example: `EdwardcherJSONInspector.open({status: "ok", items: [1,2]}, "Response")`. No redistribution licence has been assigned.
