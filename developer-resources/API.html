Native JavaScript integration reference.

01 / Vim Navigation

Declarative integration. The classic script initialises automatically when loaded; it exposes no public JavaScript methods.

Installation

Extract the download and keep the CSS and JavaScript with your site. Include the stylesheet, help trigger and dialog markup from example.html. Load the script after the markup.

<link rel="stylesheet" href="navigation.css">
<button type="button" data-navigation-help>? Help</button>
<!-- Insert the reading-dialog markup from example.html here. -->
<script src="vim-scroll.js"></script>
<script src="reading-navigation.js"></script>

DOM contract

SelectorPurpose
#reading-dialogRequired native dialog. Without it the script exits.
[data-navigation-help]Help triggers, bound at initialisation.
[data-workspace]Anchors numbered 1–5 inside the dialog. Set href to your destinations.
#reading-progressOptional reading progress indicator.

Keyboard behaviour

j/k scroll; Ctrl+D / Ctrl+U scroll half a page; q closes help; gg/G jump to beginning/end; f toggles link mode; j/k selects controls; l activates selection; Enter uses native activation; ? opens or closes help; Escape exits selection or closes help. Numbers 1–5 navigate to configured destinations. h navigates home (root on the main page). Tab remains native.

Integration constraints

Load once per page. Shortcuts ignore editable fields and modifier keys except the explicit Ctrl+D / Ctrl+U bindings. Other native dialogs in the document take precedence. Shadow DOM dialogs need their own event isolation. Root-relative links in the example must be adapted to your site. No teardown or runtime configuration API is exposed.

02 / JSON Inspector

Installation

Keep json-inspector.js and json-inspector.css in the same directory. The script loads its stylesheet into a shadow root automatically.

<script src="json-inspector.js"></script>
<script>
  EdwardcherJSONInspector.open({status: "ok", items: [1, 2]}, "Response");
</script>

Method signature

EdwardcherJSONInspector.open(data, title) → undefined
ParameterContract
dataRequired JSON-serializable value.
titleOptional string; defaults to JSON Inspector.

Behaviour and errors

Each call snapshots data through JSON serialization. Cycles, BigInt and undefined root values are unsupported. Functions and undefined object properties are omitted by serialization. Use plain JSON values. Test large payloads locally.

Keyboard controls

j/k move, h/l collapse or expand, Enter toggles, / searches, n/N moves between matches, g/G jumps, Escape closes.

Security and privacy

Read-only inspection; no storage or transmission by the component. Review sensitive values before displaying or copying. Clipboard access depends on browser permissions and secure context.
