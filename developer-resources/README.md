# Edwardcher JSON Inspector
A dependency-free, read-only JavaScript/CSS component adapted from the FIDO MDS Explorer. Copy both files into the same directory and load the script with a normal script tag. Call `EdwardcherJSONInspector.open(data, "Your title")` with a JSON-serializable value. The component snapshots data, renders escaped text, isolates styles in a shadow root and uses a native modal dialog. No network calls for inspected data, no storage, no editing. Clipboard requires browser permission and a secure context. Use JSON data only (not cyclic objects, BigInt or executable objects). Large documents may be slow; test with your expected payload sizes. Do not pass secrets or personal data unless disclosure and clipboard access are appropriate. Keyboard: j/k, h/l, Enter, /, n/N, g/G, Escape.
